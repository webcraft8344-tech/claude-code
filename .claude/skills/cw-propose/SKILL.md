# 応募・提案文作成（cw-propose）

## 手順

1. `bun run cw propose <案件ID> [--bid 提示額]` を実行。`jobs/<ID>/proposal.md` に以下が出力される:
   - 求めるポイント × 自分の強み 対応表
   - 選定されたポートフォリオ（ジャンル一致 > キーワード一致 > 新しさ）
   - テンプレ差し込み済みの詳細版・短縮版（叩き台）
2. `jobs/<ID>/source.txt`（案件本文）と `clients/<クライアント>.md`（過去メモがあれば）と `bun run cw wins` の勝ちパターンを読み、叩き台を**自然な日本語に書き直す**:
   - 冒頭2行で「この案件のどこに応えられるか」を具体的に（募集文の言葉を引用して呼応させる）
   - 対応表で「未対応」の項目は、正直に書くか、近い経験で補う（経験の捏造はしない）
   - 募集文に質問事項・応募条件（例: 「冒頭に"了解"と書いて」）があれば必ず反映
   - 抽出で「不明」だった項目（取材形式・交通費・修正回数など）は確認質問として末尾に1〜2個
   - 詳細版は 600〜900字、短縮版は `profile.shortProposalChars`（既定400字）以内
3. 完成版を `jobs/<ID>/proposal_final.md` に保存し、ユーザーに両バージョンを提示する。
4. ユーザーが送信したら、送信文をファイルに保存して履歴に記録:
   `bun run cw apply <ID> --bid <提示額> --variant short|long --text <送信文ファイル>`
5. 結果が出たら `bun run cw result <ID> won|lost|no_reply|withdrawn [--note 理由]`。

## 禁止事項

- profile.json にない実績・数字・資格を作らない。
- クラウドワークス外での連絡・直接契約を持ちかける文面を書かない（利用規約違反）。
