# 案件探索・選定（cw-scout）

CLI: `bun run cw <command>`（リポジトリルートで実行。データは `$CW_HOME`、既定 `~/crowdworks-agent`）

## 手順

1. 初回のみ `bun run cw init` を実行し、`profile.json`（最低文字単価・対応できる取材形式・得意/NGジャンル・強み・自己PRテンプレ）をユーザーと一緒に埋める。
2. 案件を受け取る:
   - コピペされたテキスト → scratchpad に保存（複数案件は `=====` 行で区切って1ファイルにしてよい）
   - 保存HTML → そのままパスを渡す
3. `bun run cw scout <file...>` を実行。一覧表と判定が出力され、`jobs/<案件ID>/memo.md` が作られる。
4. 各 `memo.md` を読み、CLI では判定できない定性的なリスクを「自分用メモ」に追記する:
   - テストライティングが無償／著しく低額
   - 「文字単価」表記だが実際は構成・画像選定・入稿込み（実質単価が下がる）
   - 外部ツール（LINE・チャットワーク等）への早期誘導、個人情報の要求（利用規約違反の可能性）
   - 著作権・実績公開不可の条件（ポートフォリオに使えない）
   - 取材の日程・場所・交通費の扱いが不明
5. 最終的な一覧（判定・スコア・理由1行）をユーザーに提示する。判定の最終決定はユーザー。

## 判断のルール

- 数値（単価・文字数・納期）は CLI の抽出結果を使い、推測で埋めない。抽出できなかった項目は「不明（要確認）」として、応募時の質問候補に回す。
- 足切り（hardStops）がある案件は、ユーザーが明示的に望まない限り提案文作成に進まない。
- `bun run cw scout list` で保存済み案件の一覧をスコア順に再表示できる。
