# アイコン用人物画像：ChatGPT プロンプト

- 作成日：2026-10-01
- 用途：Threads / Instagram のアイコン（丸く切り抜かれる前提）
- 方針：絵画調・顔の半分は影（`CHARACTER.md` 6章）。実写風の顔写真にはしない

## メインプロンプト（そのまま貼り付け）

```
SNSのプロフィールアイコン用に、正方形（1:1）の絵画調イラストを1枚作ってください。

【人物】
・日本人女性の占い師。年齢は30代前半くらいに見えるが、年齢不詳の雰囲気
・黒に近い深い藍色の髪。長さは肩下まで、まっすぐで艶がある
・顔は左斜め45度の横顔。顔の右半分は深い影に沈み、ろうそくの光が当たった左目と頬の輪郭だけが見える
・目元は切れ長で、静かで鋭いまなざし。視線はこちらではなく、少し下の手元に落としている
・表情は無表情に近く、笑顔はなし。近寄りがたく、すべてを見通しているような落ち着き
・肌は自然で、化粧は控えめ。唇は落ち着いた色

【服装・小物】
・深い藍色（ほぼ黒に近い紺）のハイネックのローブ。襟元と袖口に、細い金糸で星図（星座を結んだ線と円）の刺繍
・胸元のあたりに、古い真鍮のアストロラーベ（円盤状の天文器具）を片手で持っている。手は細く、指先まで丁寧に描く
・アクセサリーは、細い金の三日月のピアスを片耳だけ

【背景】
・暗い藍色から黒へのグラデーション
・背景にうっすらと、金色の細い線で描いた古い星図（円の目盛り・星座線）
・人物の頭の後ろあたりに、三つの円が重なり、その交わる一点だけが小さく金色に光っている図形（光は控えめに）

【光と質感】
・光源は画面左下の、ろうそく1本だけ。暖かい金色の光
・明暗のはっきりしたキアロスクーロ（レンブラント風）の光
・古典的な油絵の質感。筆のタッチがわずかに残る
・色は、深い藍・黒・金・月光のような淡い白の4色にまとめる

【構図（アイコン用に重要）】
・顔と手元のアストロラーベが、画像の中央の円の中に収まるように配置する（四隅は丸く切り取られても問題ないように）
・人物は胸から上のバストアップ
・小さく表示しても横顔のシルエットが分かるように、顔の輪郭と背景の明暗差をはっきりつける

【入れないもの】
・文字、ロゴ、透かし
・笑顔、かわいい雰囲気、アニメ調、ピンクや明るい色
・実写のような写真風の顔
・指の数の崩れ、不自然な手
```

## 別案（気分を変えたいとき、メインプロンプトの最後に1行足す）

**後ろ姿（いちばん謎が深い）**
```
【変更】人物は後ろ姿にし、肩越しに少しだけ横顔のあごの線が見える構図にしてください。顔はほとんど見せず、壁一面の古い星図に向き合っている姿にしてください。
```

**フードで目元だけ（いちばん近寄りがたい）**
```
【変更】深い藍色のフードを目深にかぶり、フードの影の中から、ろうそくの光を受けた両目だけが静かにこちらを見ている構図にしてください。
```

**ベールで口元を隠す（神秘性を強める）**
```
【変更】顔は正面に近い角度にし、鼻から下を薄い藍色のベールで隠してください。目だけがこちらをまっすぐ見ています。
```

## 仕上げで使う追加の指示（生成後に送る）

| 気になる点 | ChatGPT に送る文 |
|-----------|------------------|
| 明るすぎる | 全体をもう一段暗くし、ろうそくの光が当たっている部分以外は影に沈めてください。 |
| 若く・かわいく見える | 表情をもっと静かで厳かにし、大人びた落ち着きのある顔立ちにしてください。笑みは消してください。 |
| 写真っぽい | 実写感を弱め、古典的な油絵の筆のタッチをはっきり出してください。 |
| 背景がうるさい | 背景の星図の線を細く薄くし、人物の横顔が一番目立つようにしてください。 |
| 丸く切ると顔が欠ける | 人物をもう少し小さくして中央に寄せ、周りに余白をとってください。 |
| 手が崩れている | 手の形を自然に直してください。指は5本で、アストロラーベを軽く支える持ち方にしてください。 |

## 使うときの注意

- **「本人の写真」とは言わない**。絵として使う（`CHARACTER.md` 6-2）
- 生成した画像を使う前に、ChatGPT（OpenAI）の利用規約で商用利用の条件を確認する
- 色味をそろえるため、エンブレム（`assets/emblem.png`）と並べて違和感がないかを見て選ぶ
