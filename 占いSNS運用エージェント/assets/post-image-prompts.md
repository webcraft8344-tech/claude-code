# 投稿用イラスト「紫苑」：ChatGPT プロンプト

- 作成日：2026-10-09
- 用途：Threads の3連投（1/3）・Instagram に付ける画像。毎回同じ画風・同じ人物にして「画像だけで紫苑とわかる」ようにする（`output/2026-10-09/benchmark-tsukuyomi.md` ④）
- 落款：`assets/seal-shion.png`（赤い印・背景透過）を、できた画像の右下に重ねる

## 使い方
1. ChatGPT に `assets/portrait.png`（今のアイコンの人物画）を添付する
2. 下の「共通プロンプト」を貼り、最後の【場面】だけを差し替える
3. できた画像の右下に、落款の画像を小さく重ねる（Canva・スマホの写真編集アプリなど）

## 共通プロンプト（毎回そのまま貼る）

```
添付した画像の人物と同じ女性を主人公に、SNS投稿用のイラストを1枚作ってください。

【画風（毎回同じにする）】
・古い和紙に描いた、セピア色の墨絵（水墨画）風イラスト
・色はセピアと墨の黒を中心に、星や月の光だけを細い金色で入れる。ほんのわずかに薄紫を混ぜる
・にじみやかすれのある筆のタッチ。紙の質感が見える
・静かで、少し切ない、夜の空気感
・横長（16:9）

【人物（毎回同じにする）】
・30代前半に見える日本人女性。黒に近い深い藍色の、長くまっすぐな髪
・深い藍色のハイネックの服。襟元に細い金の星図の刺繍
・片耳だけに、細い金の三日月のピアス
・顔は横顔か斜め後ろ姿。正面は向かない。表情は静かで、笑顔はなし

【場面】
（ここを毎回差し替える）

【入れないもの】
・文字、ロゴ、透かし、落款
・アニメ調、写真のような顔、ピンクや明るい色
・指の数の崩れ、不自然な手

【構図】
・右下の角は、印を押すために何も描かずに余白を残す
```

## 【場面】の差し替え例（投稿のテーマに合わせて選ぶ）

| 投稿のテーマ | 【場面】に貼る文 |
|-------------|-----------------|
| 送れない一通・忘れられない人 | 夜の窓辺の机で、彼女が便箋に手紙を書いている。窓の外には細い三日月と、うっすら金色の星座線。机の上にはスマホが伏せて置いてある |
| 新月・手放す | 月のない夜空の下、川辺にしゃがみ、折りたたんだ一枚の紙をそっと水に浮かべている。水面に星が小さく映っている |
| 待つ刻 | 雨上がりの夜、縁側に座り、膝の上で手を重ねて、静かに夜空を見上げている後ろ姿。雲の切れ間に星がひとつ |
| 動く刻 | 夜明け前の坂道を、彼女がゆっくり歩き出している後ろ姿。空の端が少し明るく、金色の星がひとつだけ残っている |
| 三つの星図（心・星・言葉） | 机の上に広げた古い星図に、三つの円が重なって描かれている。彼女はその交わる一点に、細い指先をそっと置いている |
| 金星逆行・昔の恋を思い出す | 古いアルバムを膝に置き、一枚の写真を見つめる横顔。窓の外に明るい金星がひとつ光っている |
| 束縛していた過去（体験談） | 薄暗い部屋で、スマホの画面の光だけが彼女の横顔を照らしている。画面は見えない。部屋の隅に月明かりが差し込んでいる |
| 自分を整える | 朝の柔らかな光の中、湯気の立つお茶を両手で包み、目を閉じて深呼吸している横顔 |

## 仕上げで使う追加の指示（生成後に送る）

| 気になる点 | ChatGPT に送る文 |
|-----------|------------------|
| 人物が別人になった | 添付した画像の人物と、髪型・服・三日月のピアスをそろえてください。顔は横顔のままにしてください。 |
| 色が明るい・カラフル | セピアと墨の色に戻し、金色は星と月の光だけにしてください。 |
| 写真っぽい・アニメっぽい | 墨絵の筆のにじみとかすれを強くし、和紙の質感を出してください。 |
| 文字が入った | 画像の中の文字をすべて消してください。 |
| 右下に何か描かれている | 右下の角を何も描かない余白にしてください。 |

## 使うときの注意
- 毎回の画像の画風がそろっているか、前の画像と並べて確かめる
- 「本人の写真」とは言わない。絵として使う（`CHARACTER.md` 6-2）
- 商用利用の条件は ChatGPT（OpenAI）の利用規約で確認する
