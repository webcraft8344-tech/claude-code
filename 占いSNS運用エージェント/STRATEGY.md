# STRATEGY.md — 恋愛占いSNS マーケティング戦略


## 1. アカウント概要

| 項目 | 内容 |
|------|------|
| アカウント名 | さき＠愛され案内人 |
| 占術 | 恋愛心理学 ＋ 星回り ＋ AI の独自占術 |
| 主要プラットフォーム | Threads（メイン）/ Instagram |
| ゴール（6か月） | Threads フォロワー1,500人 / Instagram フォロワー5,000人 / 有料鑑定 月20件 |

## 2. ターゲット（ペルソナ）

**メインペルソナ：ミユ（28歳・会社員）**

- 片思い中、または付き合って1〜2年で将来に不安がある
- 通勤中・寝る前にスマホでSNSを見る（閲覧ピーク：7〜8時、21〜24時）
- 「彼の気持ちが知りたい」「連絡が来ない理由」「復縁できる？」で検索する
- 当たるかどうかより**「読んで気持ちが軽くなるか」**を重視
- 強い言葉・怖い予言は苦手。やさしく背中を押してほしい

**サブペルソナ**
- 20代前半の学生：片思い・告白のタイミングに関心
- 30代後半：婚活・結婚のタイミングに関心

## 3. コンセプト

**「不安な夜に、そっと灯りをともす恋占い」**

- 怖がらせない、でも甘やかしすぎない
- 占い結果を「今日できる小さな行動」に変える
- 読者が「自分のことだ」と感じる具体的なシチュエーション描写

## 4. トーン＆マナー

| やること | やらないこと |
|----------|--------------|
| やわらかい語尾（〜かも、〜してみて） | 断定・命令口調（〜しなさい、絶対〜） |
| 絵文字は1投稿3〜5個まで（🌙✨🔮💌） | 絵文字・記号の多用 |
| 読者を「あなた」と呼ぶ | 上から目線の説教 |
| ネガティブ結果＋行動ヒント | ネガティブ結果のみで終わる |

## 5. コンテンツの柱（投稿配分）

| 柱 | 割合 | 例 |
|----|------|-----|
| ① 選択式占い（ピックアップ） | 40% | 「3枚から直感で選んで。彼があなたに伝えたいこと」 |
| ② 星座・誕生月別の恋愛運 | 25% | 「今週の12星座別 恋愛運」 |
| ③ 恋愛お悩み相談・共感 | 20% | 「既読スルーが続くときの彼の本音」 |
| ④ 恋愛心理学・星回りの豆知識 | 10% | 「返信が遅い人の心理と、今週の星回り」 |
| ⑤ 告知・PR | 5%以下 | 有料鑑定・イベント告知 |

## 6. プラットフォーム別方針

- **Threads（メイン）**：毎日の星回りメッセージ・恋愛心理の短文・共感投稿。会話が生まれる問いかけで締め、返信で交流。新規フォロワー獲得の主戦場
- **Instagram**：カルーセル（5〜8枚）＋リール。保存数を最重要KPIに。Threads で反応の良かったテーマを深掘りして展開

## 7. 投稿頻度

- Threads：1日2〜3投稿
- Instagram：フィード 週3〜4本 / ストーリーズ 毎日 / リール 週1〜2本
