# writing.md — 鑑定文・投稿キャプション作成

## 目的

リサーチで決めたネタを、`STRATEGY.md` のトーンに沿った投稿原稿（画像内テキスト＋キャプション＋ハッシュタグ）に仕上げる。

## 入力

- ネタ（`output/*/research.md` の候補、またはユーザー指定）
- プラットフォーム・形式（Threads 短文 / Instagram カルーセル / リール）

## 手順

### Step 1. 構成を決める

形式ごとの基本構成：

**Instagram カルーセル（選択式占い・6〜8枚）**
1. 表紙：問いかけ＋「直感で1つ選んでね」
2. 選択肢：A / B / C のモチーフ（色・数字・星など）
3. A の結果
4. B の結果
5. C の結果
6. まとめ：全員に共通するひと言アドバイス
7. （任意）保存・フォローの呼びかけ

**Instagram リール（15〜30秒）**
- 0〜1秒：「今、頭に浮かんだ数字は？」などのフック
- 本編：選択肢 → 各結果を短く
- 最後：「当たってたらコメントで教えて🌙」

**Threads 短文（メイン）**
- 1行目で対象を絞る（例：「連絡を待っているあなたへ」）
- 200〜400字で完結（上限500字）、最後に行動ヒント
- 朝 7:30 枠は 100〜200字の短文（参加型・星回り・心理学の豆知識）。参加型は投稿直後に自分で返信して結果を置く
- 締めは返信したくなる問いかけ（例：「あなたは待つ派？送る派？」）
- 長い内容はスレッド（連投）にし、1投稿目だけで意味が通るようにする

**Threads を伸ばすルール（2026-10-02 検証反映。詳細は `output/2026-10-02/analysis.md`）**
- 1行目は「日付・数字・出来事・意外な事実・体験の一場面」で始める。自己紹介や「〜な夜」で始めない
- トピックタグは旬・小さめ（金星逆行／新月／星読み／恋愛心理学など）。「復縁」単独は避ける
- 知らない人向けは 120〜180字。1〜2行目は命令形にしない（「〜なさい」は最後の呼びかけだけ）
- 主力の時刻は 12:00／20:30。固定投稿以外は返信欄にリンクを付けない
- 投稿の前後に、同じジャンルの他の人の投稿へ3〜10件返信する。返信が来たら1時間以内に返す
- 翌日 `output/metrics-log.md` に数字を記録する

**フォロワー100人までの方針（2026-10-05 検証反映。詳細は `output/2026-10-05/analysis.md`）**
- 入口の主力は、有力アカウントへのコメント（1日10〜15件・同じ3〜5アカウントに毎日）。型は「投稿主の主張に乗る一言（やっぱり〜）→ 事実の一文（束縛で一度切れた縁が戻った当事者）または紫苑だけの見方（心・星・言葉のどれか一つ）→ わかると思える一文」、120字以内。他人の場なので丁寧語でよい。宣伝の一言は入れない
- パワーワードは事実から作る（当事者／霊視はできない・家系でもない／交わらなければ「まだ」と告げる）。霊視・家系・架空の実績は名乗らない（`output/2026-10-05/analysis.md` 5-3）
- 参加型は昼12時に残す（10/5 昼：表示115・プロフ閲覧15＝閲覧率13%で最高）。「今日の動く刻・待つ刻」と組み合わせ、答えは自分の返信に置く
- 夜 20:30 は表示が伸びない（10〜15）。当面、2本目は朝 7:30 で試し、夜はコメント活動にあてる
- 昼12時は「日付・出来事」から入る“今日の星図”を毎日（「金星逆行、11日目。」など日数を数えるシリーズ）
- 無料鑑定の告知は Threads では週1回まで。同じトピックタグは1日1回まで

**バズ投稿から取り入れた型（2026-10-21。詳細は `output/2026-10-21/threads-buzz-adapt.md`）**
- 人に言えない本音を先に言う＋「そんな方、いますか」／「第1位は」のランキング
- 二つの言葉の対比でモヤモヤに名前をつける（金星の縁と月の縁、外の顔と内の顔）
- 「どちらも間違いではない」で罪悪感を外す／「見るのは一つだけ」／名言で締める
- 霊視・波動・「何百人と視た」・「あなたの直感は正しい」は使わない。権威は星図・恋愛心理学・当事者で示す

**ネガティブ訴求（リール・2026-10-18。詳細は `output/2026-10-18/reel-negative-ideas.md`）**
- 「対策しなかったら困る場面」を0〜2秒に一つだけ見せる → 原因 → 今日できる対策を一つ → 安心の未来で終える
- 困る場面は行動の結果（送り方・見方）に限る。運命や不幸の予言、読者を責める言い方、鑑定を対策にすることはしない

**信頼で売れる5つの構造（2026-10-14 方針。例：`output/2026-10-17/threads-1017-1019.md`）**
1. 共感から入る：1本目に「私も〜だった」（体験は実話の範囲だけ）。**ただし1行目には置かない**。1行目は反転か日付・旬で始め、「私も」は2〜4行目（10/17・10/18 の「私も」始まりは100未満：`output/2026-10-21/analysis-weekend.md`）
2. 悩みを言語化する：読者のモヤモヤを、そのまま言葉にする
3. 小さな気づきを与える：2本目だけで「なるほど」と思える答え（80字以内）
4. 解決の続きを note に置く：Threads＝気づき、note＝深い答え。リンクは3本目のあとの**自分への返信（4本目）**にだけ置く
5. 売ろうとしない：「必要な方だけ、どうぞ」。note の最後も同じ
- 3日ほどを一つの流れにし、note 1本にまとめる（例：言葉 → 心 → 時 ＝三つの星図）

**試験の結果（2026-10-13。詳細は `output/2026-10-13/analysis-1010-1012.md`）**
- 昼12時は「宣言の1行目＋3連投（1本目は2〜3行）＋画像＋参加の合図とお返し」を固定する
- 旬のタグ（新月・満月・星座シーズンなど）を当日・前日に合わせる
- 朝は「宣言＋言い換え」の1本。「〜日目」で始めない
- 3本目の最後に、翌日の予告を1行入れる（フォローの理由。条件にはしない）
- 1本目は答えを伏せて終える（答えを言い切ると続きが読まれない：10/10 は17%）。2本目は80字以内で、答え＋紫苑の体験をひと言
- 返信の合図は「当てはまった方は『私も』とだけ」のように、自分を名乗れる一言にする

**参考アカウントの型（2026-10-09。詳細は `output/2026-10-09/benchmark-tsukuyomi.md`）**
- 1行目は「本当のことを言う」宣言：「正直に言います。」「飛ばさないでほしい。」「嘘のような話ですが、」「はっきり言います。」
- 2行目で悩みの意味を言い換える（心理学・星回りから見た「責めなくていい理由」。霊的な理由は使わない）
- 3連投（1/3）：1本目は2〜3行＋画像、2本目に理由、3本目に「今日やることは、ひとつ。」
- 画像は毎回同じ画風（墨と金の星図風＋落款「紫苑」）
- 丁寧語の断言を試す（常体と比べる）

**伸びる型（2026-10-04 他アカウント分析より。詳細は `output/2026-10-04/viral-analysis.md`）**
- 続く型：本文を途中で切り「（続きは返信に）」→ 自分で返信して続きを書く
- リフレーム：読者の“短所”を“想いの深さの証拠”に言い換える
- 比喩：月・星図・羅針盤など、世界観に合う身近な比喩で心の状態を見せる
- 数字と引き：「〜は四つある」「見るべきは一つ。それは──」→ 答えは返信へ
- サイン一覧：「〜な時 → 〜の刻」。三つの星図に当てはめる
- 期限＋合図：「今夜21時まで」「🌙をひとつ」。いいね・フォローは条件にしない
- 引用は出どころが確かな言葉だけ（紫苑を救った占いの言葉、古くからの格言など）。有名人の発言の引用は使わない
- 使わない：「〜な人にしか届かない」「いいねした人は〜が叶う」などの結果の約束

### Step 2. 鑑定文を書く

各結果は次の3段構成にする。

1. **今の状態**（共感）：「最近、彼の返信が短くなった気がしていませんか？」
2. **心理と星回りからのメッセージ**（解釈）：「こういうときの彼は〜という心理になりやすいもの。今週の星回りも〜を後押ししています」
3. **行動のヒント**（前向き）：「今週は自分から軽い話題を1つ送ってみて」

ルール：
- 各結果は同じくらいの分量・同じくらいの前向きさにする（選んだ結果で優劣をつけない）
- ネガティブな結果でも「気づき」「準備期間」など建設的に言い換える
- 「絶対」「必ず」「運命確定」は使わない

### Step 3. キャプションを書く

```
［1行目：フック（保存したくなる一文）］

［2〜4行：投稿の内容紹介・共感］

［選び方・読み方の案内］

［行動の呼びかけ：保存 / コメント / フォロー］

占いは、あなたが自ら選ぶための地図である。

［ハッシュタグ］
```

### Step 4. ハッシュタグ

- Instagram：合計 10〜15 個
- Threads：トピックタグ 1 個（投稿テーマに合うもの）
- 組み合わせ：大（#恋愛占い #恋愛心理学）3〜4個 ＋ 中（#片思い占い #復縁占い）5〜6個 ＋ 小・独自（#星図師紫苑 #復縁の星図）2〜3個

### Step 5. セルフチェック

提出前に次をすべて確認する。

- [ ] `CLAUDE.md` 3章の禁止事項に触れていない
- [ ] 不安をあおる断定表現がない
- [ ] ネガティブ結果にも行動ヒントがある
- [ ] 選択肢ごとの分量・前向きさに大きな差がない
- [ ] `CHARACTER.md` の語り口（常体の言い切り・絵文字なし・「！」なし）。**投稿の最後に「— 紫苑」の署名は入れない**（2026-10-04 廃止）
- [ ] PR・広告を含む場合、冒頭に「PR」表記がある
- [ ] 誤字脱字がない
