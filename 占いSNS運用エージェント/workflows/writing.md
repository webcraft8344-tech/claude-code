# writing.md — 鑑定文・投稿キャプション作成

## 目的

リサーチで決めたネタを、`STRATEGY.md` のトーンに沿った投稿原稿（画像内テキスト＋キャプション＋ハッシュタグ）に仕上げる。

## 入力

- ネタ（`output/*/research.md` の候補、またはユーザー指定）
- プラットフォーム・形式（カルーセル / リール / X短文）

## 手順

### Step 1. 構成を決める

形式ごとの基本構成：

**Instagram カルーセル（選択式占い・6〜8枚）**
1. 表紙：問いかけ＋「直感で1つ選んでね」
2. 選択肢：A / B / C のカード（またはモチーフ）
3. A の結果
4. B の結果
5. C の結果
6. まとめ：全員に共通するひと言アドバイス
7. （任意）保存・フォローの呼びかけ

**リール / TikTok（15〜30秒）**
- 0〜1秒：「今、頭に浮かんだ数字は？」などのフック
- 本編：選択肢 → 各結果を短く
- 最後：「当たってたらコメントで教えて🌙」

**X 短文**
- 1行目で対象を絞る（例：「連絡を待っているあなたへ」）
- 140字前後で完結、最後に行動ヒント

### Step 2. 鑑定文を書く

各結果は次の3段構成にする。

1. **今の状態**（共感）：「最近、彼の返信が短くなった気がしていませんか？」
2. **カード・星からのメッセージ**（解釈）：「出ているのは〇〇。これは〜を表します」
3. **行動のヒント**（前向き）：「今週は自分から軽い話題を1つ送ってみて」

ルール：
- 各結果は同じくらいの分量・同じくらいの前向きさにする（選んだ結果で優劣をつけない）
- ネガティブなカードでも「気づき」「準備期間」など建設的に言い換える
- 「絶対」「必ず」「運命確定」は使わない

### Step 3. キャプションを書く

```
［1行目：フック（保存したくなる一文）］

［2〜4行：投稿の内容紹介・共感］

［選び方・読み方の案内］

［行動の呼びかけ：保存 / コメント / フォロー］

※占いは楽しむためのものです。最後に決めるのはあなた自身🌙

［ハッシュタグ］
```

### Step 4. ハッシュタグ

- 合計 10〜15 個（Instagram）、X は 1〜2 個
- 組み合わせ：大（#恋愛占い #タロット占い）3〜4個 ＋ 中（#片思い占い #復縁占い）5〜6個 ＋ 小・独自（#愛され案内人）2〜3個

### Step 5. セルフチェック

提出前に次をすべて確認する。

- [ ] `CLAUDE.md` 3章の禁止事項に触れていない
- [ ] 不安をあおる断定表現がない
- [ ] ネガティブ結果にも行動ヒントがある
- [ ] 選択肢ごとの分量・前向きさに大きな差がない
- [ ] 絵文字は3〜5個程度
- [ ] PR・広告を含む場合、冒頭に「PR」表記がある
- [ ] 誤字脱字がない

## 出力フォーマット

`output/YYYY-MM-DD/captions.md` に、1投稿ずつ次の形式で保存する。

```markdown
## 投稿1：新月に届く彼からのメッセージ
- プラットフォーム / 形式：Instagram / カルーセル7枚
- 推奨投稿日時：10/2 21:00

### 画像テキスト
1. 表紙：…
2. …

### キャプション
…

### ハッシュタグ
#恋愛占い #タロット占い …
```

## 完了条件

- 依頼された本数の原稿がすべて揃い、セルフチェックを全項目通過している
