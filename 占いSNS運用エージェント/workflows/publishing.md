# publishing.md — 自動投稿・スケジューリング連携

## 目的

完成した原稿を、最適な日時で各SNSに予約・投稿する。
**実際の投稿・予約登録は、必ずユーザーの承認後に行う**（`CLAUDE.md` 5章）。

## 入力

- 原稿ファイル（`output/*/captions.md`）
- 画像・動画ファイルの保存場所
- 使用する投稿ツール（下記「連携先」参照）

## 連携先（運用に合わせて選択）

| 方法 | 用途 | 必要な設定 |
|------|------|------------|
| Instagram Graph API | Instagram の予約・投稿 | ビジネスアカウント + Facebookページ連携、`IG_ACCESS_TOKEN` |
| Threads API | Threads の投稿（メイン） | Meta 開発者アプリ + Threads アカウント連携、`THREADS_ACCESS_TOKEN` |
| 予約投稿ツール（Buffer / Later / Meta Business Suite など） | まとめて予約 | ツール側のアカウント・API |
| 手動投稿 | API未連携時 | なし（投稿用チェックリストを出力） |

> 🔒 トークン類は環境変数で扱い、ファイルやログに書かない。

## 手順

### Step 1. 原稿の最終確認

- `writing.md` のセルフチェックが全項目通過しているか確認する
- 画像・動画ファイルがすべて揃っているか確認する（枚数・順番・サイズ）
  - Instagram フィード：1080×1350（4:5）推奨
  - リール：1080×1920（9:16）

### Step 2. スケジュール案の作成

`STRATEGY.md` の投稿頻度・閲覧ピークをもとに日時を割り当てる。

- 基本の時間帯：朝 7:00〜8:00 / 夜 21:00〜23:00
- 新月・満月などのイベント投稿は当日の夜に
- 同じ「コンテンツの柱」が2日続かないようにする
- PR投稿は週1本まで、前後は通常投稿で挟む

### Step 3. ユーザー承認（必須）

次の形式でスケジュール案を提示し、承認を得る。

```
【投稿スケジュール案】
| 日時 | SNS | 形式 | タイトル | PR |
|------|-----|------|----------|----|
| 10/2(木) 21:00 | Instagram | カルーセル | 新月に届く彼からのメッセージ | - |
| 10/3(金) 07:30 | Threads | 短文 | 連絡を待っているあなたへ | - |

この内容で予約してよろしいですか？（修正があれば指示してください）
```

### Step 4. 予約・投稿の実行

- 承認された分だけ、連携先ツールで予約登録する
- API未連携の場合は、手動投稿用チェックリスト（日時・原稿・画像パス）を出力する
- エラーが出たら再試行は1回まで。解決しなければ内容をユーザーに報告する

### Step 5. 記録

`output/YYYY-MM-DD/schedule.md` に以下を記録する。

| 日時 | SNS | タイトル | ステータス（予約済 / 投稿済 / 失敗） | 投稿URL |
|------|-----|----------|---------------------------------------|---------|

### Step 6. 投稿後フォロー（24〜48時間後）

- 保存数・いいね・コメント・リーチを記録する
- `STRATEGY.md` 8章のKPIと比較し、次回の `research.md` Step 4 で使えるようにメモを残す
- コメントへの返信案を作る（返信の実行はユーザー承認後）

## 完了条件

- 承認済みの投稿がすべて予約済み、または手動投稿チェックリストが出力されている
- `schedule.md` が更新されている
