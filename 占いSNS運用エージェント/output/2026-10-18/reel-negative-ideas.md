# リール：ネガティブ訴求（「対策しなかったら困る場面」から考える）のネタ出し

- 作成日：2026-10-18
- 考え方（ご本人の方針）：起こると困る未来を先に見せ、その対策を教える＝読者への親切。「こうなりたい」と同じくらい「この状態にはなりたくない」という気持ちがある

## 1. 構成（20秒）

| 秒 | 役割 | 中身 |
|----|------|------|
| 0〜2 | **困る場面**（フック） | 一場面だけを具体的に。「深夜2時に送った長文。朝、既読のまま。」→ 見た瞬間に「それは困る」 |
| 2〜6 | 場面を広げる | その後に起きる困りごとを1〜2つ。「消せない。追いLINEもできない。一日中スマホを見てしまう」 |
| 6〜9 | 原因 | なぜ起きるか。心理（不安で送る）・星回り（逆行期）・習慣 |
| 9〜16 | **対策** | 今日からできることを1つ。無料で、すぐできること |
| 16〜20 | 安心の未来＋行動 | 「これだけで、〇〇しなくて済む」→ 保存／フォロー（次回予告）／星座コメント |

## 2. ネガティブ訴求のルール（`CLAUDE.md` 3章との線引き）

| やる | やらない |
|------|----------|
| 困る場面は**行動の結果**（送り方・見方・言い方）にする | 運命や不幸の予言（「このままだと縁が切れる」「二度と戻らない」） |
| 「よくある」「〜しがち」で一般化し、**「私もやった」**で共感する | 読者を責める（「だからあなたは振られる」） |
| 対策は**無料で、今日できる一つ** | 対策を鑑定・商品にする（「鑑定を受けないと手遅れ」） |
| 最後は**安心の未来**で終える | 不安のまま終わらせる |
| 1本に困る場面は1つ | 困ることを並べて怖がらせる |

## 6. 作り方
- 台本②・③は、ナレーション付きのリールとして書き出せる（`tools/reel` ＋ VOICEVOX 冥鳴ひまり）。キャプションに「VOICEVOX:冥鳴ひまり」のクレジットが必要
