### 伸びている型（要素）
1. **全員が「自分の組み合わせ」を探す**：12×12＝144通り。誰もが当事者になる
2. **読み切れない速さ**（1ページ約2秒・12行）→「**長押しで止めて確認**」→ 止める・見直す → **視聴時間が動画の長さを超える**（Instagram が「最後まで、何度も見られた」と判断する）
3. **感情のあるタイトル**：「好きすぎて辛い」＝甘さと苦さ。気になる
4. **ページごとに順位の色を変える**：進んでいる感覚。最後まで見る
5. **相手に送りたくなる**：「私たち何位？」→ リポスト574・シェア99
6. **最後の一言で、コメント＝自分の星座**：考えなくていい一語。コメント513件 → 表示がさらに広がる
7. **コメントした人に、無料の占いを届ける** → ここで見込み客のリストになる（DM → LINE）

## 2. 紫苑への転用

| 参考 | 紫苑 |
|------|------|
| 好きすぎて辛い相性 | **別れても忘れられない相性**（復縁の読者の悩みそのもの） |
| 順位の根拠なし | 星の角度（アスペクト）と星座の性質から算出。「占いはエンターテインメント」と明記 |
| 毎月の無料占い | **11月の「動く刻・待つ刻」**（星座ごと）を LINE で届ける。12星座分を用意しておけば、人数の上限なしで自動で届けられる（無料鑑定の月30名の枠を使わない） |
| コメント＝星座 | 同じ。コメントした人に DM で LINE を案内 → LINE で星座を送ると自動で届く |

**流れ**：リールを見る → 自分の組み合わせを探す（長押し）→ 星座をコメント → DM で LINE の案内 → LINE 追加＋「蠍座」などと送る → 11月の星図が自動で届く → （必要な方だけ）無料鑑定「星図希望」

## 3. 投稿（コピペ用）

### キャプション
```
【星座×星座】別れても忘れられない相性

あなたと、あの人の組み合わせは何位でしたか。
速くて読めない方は、画面を長押しして止めてください。

順位は、ふたりの星座がつくる角度と、星座の性質から読んでいます。
上位ほど、離れても心のどこかに残りやすい組み合わせです。

──────
【11月の星図・無料】
あなたの「星座」をコメントしてください。
11月の「動く刻・待つ刻」を、DMでお届けします。
──────

※占いはエンターテインメントです。最後に決めるのは、あなた自身です。

#星座占い #相性占い #復縁 #復縁したい #元彼 #忘れられない人 #恋愛占い #星読み #占い #12星座 #星図師紫苑 #復縁の星図
```
- 投稿時刻：21:00〜22:00
- カバー：1〜12位の表（`reel-wasurerarenai-cover.png`）
- 曲：静かなピアノなど。歌詞のない曲

### コメントした人への DM（手動で送る・1時間以内）
```
コメントありがとうございます。
〇〇座さんの11月の「動く刻・待つ刻」は、公式LINEでお届けしています。

LINEを追加して、「〇〇座」とひと言だけ送ってください。すぐに届きます。
https://lin.ee/OjyVyly
```
- コメントへの返信にも「DMをお送りしました🌙」と一言返す（コメント欄が会話になり、表示が伸びる）
- 1日30件を超えるようなら、Meta 公認の自動 DM ツール（ManyChat など）の導入を検討する

### 注意
- コメントは「受け取りの合図」。**フォロー・いいねは条件にしない**（`workflows/writing.md` の方針どおり）
- 順位が低い組み合わせを否定しない。キャプションでも「上位ほど、離れても残りやすい」とだけ書き、下位を悪く言わない
