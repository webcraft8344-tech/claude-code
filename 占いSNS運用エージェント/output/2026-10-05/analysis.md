## 1. いちばん大事な発見

**同じ紫苑の言葉でも、自分の投稿だと 27〜31、他の人の投稿の下だと 4,000 以上見られた。**

- 言葉の中身は、届く人に届いている（いいね8）
- 問題は「中身」ではなく、次の2つ
  - **入口**：自分の投稿は、フォロワーがほぼいないので、最初に見せてもらえる人数がとても少ない
  - **出口**：コメントで知った人が、プロフィールへ来て、フォローする理由がまだない

だから、当面は「自分の投稿を伸ばす」より、**コメントで出会った人を、プロフィールでフォローに変える**ことに力を寄せる。

## 2. 広がらなかった要因の仮説

## 3. 改善策

### A. コメント運用を“主力の入口”にする（今日から）

1. **1日10〜15件**。投稿の前後に分けて書く（朝・昼・夜）
2. **同じ有力アカウント3〜5つに絞り、毎日コメントする**。同じ人の読者に、名前を何度も見てもらう（C3）
3. **型を固定する**（120字以内）
   ```
   ［投稿主の言葉を受ける一言］
   ［紫苑だけの見方：心・星・言葉のどれか一つ］
   ［読んだ人が「わかる」と思う一文で終える］
   ```
   例（「既読のまま返事がない」系の投稿に）
   ```
   既読のまま返ってこない時、
   相手は「責められる気配」を感じて黙っていることが多い。
   心理学でいう回避。
   今は金星逆行の最中。送る言葉より、送らない時間のほうが届く時期だ。
   ```
4. **やらないこと**：「プロフィール見て」「LINEで鑑定」など宣伝の一言。嫌われ、表示も減る
5. **伸びたコメントには、自分で続きを1つ返信する**。会話が続くほど長く表示される。返信が来たら1時間以内に返す
6. **毎日の記録**：コメントの表示数・いいね・プロフィール閲覧・フォロー増加（インサイトの「プロフィールのアクティビティ」）

### B. プロフィールを「フォローの理由」に変える（今日から）

1行目を、抽象的な「刻を読む」から、**フォローすると何が届くか**に変える。

**Threads プロフィール（改訂案・92字）**
```
復縁を望む人へ。毎日12時、今の「動く刻・待つ刻」を置く。
心・星・言葉――三つが交わる一点しか語らない星図師。
かつて愛を縛り、すべてを失った者として。
▼無料鑑定（月30名）はLINEに
```
- 「毎日12時」と決めることで、フォローする理由と、また見に来る理由になる
- 毎日12時の投稿は、今のスケジュール（主力 12:00）のまま続けられる

### C. 固定投稿を「自己紹介」から「いちばん響く一場面」に替える

プロフィールに来た人が最初に読むのは固定投稿。名乗りではなく、体験の一場面で引き込む。

**固定投稿（改訂案・153字）**
```
止まっていた縁が、また動き出した夜。
私が送ったのは、短い一通だけだった。

かつて私は、愛する人を縛り、失った。
何も見えない夜、ひとつの占いが言った。
「今は動く時ではない。まず、あなた自身を整える時」

執着を手放してから送った一通で、ふたりの時間はまた動き始めた。

ここでは毎日、あなたの「動く刻・待つ刻」を読む。
```
- 自分への返信（リンク）は今までどおり LINE の URL
- 「復縁できる」と約束する言い方は避け、実話（関係がまた動き始めた）の範囲で書いている

### D. 自分の投稿の作り方を変える

1. **参加型は、フォロワー100人までお休み**（H2）。代わりに「本文だけで答えまで完結する型」にする。締めは、返信しなくても読んでもらえる問い、または「🌙をひとつ」
2. **昼12時は「日付・出来事」から入る“今日の星図”を毎日**（H3・プロフィールの約束）
   - 例：「金星逆行、11日目。」「新月まで、あと6日。」のように、**日数を数えるシリーズ**にする。続けて見る理由になる
3. **無料鑑定の告知は、Threads では週1回まで**（H4）。告知は LINE と固定投稿に任せる
4. **同じタグは1日1回まで**（H5）。昼は「金星逆行」か「新月」、夜は「恋愛心理学」
5. **夜は「続く型」を続ける**（③の数字を見てから判断）

### E. 2週間で確かめる数字

| 指標 | 今 | 2週間後の目安 |
|------|----|---------------|
| 自分の投稿の表示（1本） | 27〜31 | 100以上 |
| コメントの表示（1日合計） | 4,000（1件） | 毎日 3,000以上 |
| プロフィール閲覧（1日） | 未計測 | 30以上 |
| プロフィール閲覧 → フォロー | 未計測 | 10%以上 |
