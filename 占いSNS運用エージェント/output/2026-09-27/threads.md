## 投稿1：夜になると元彼を思い出す（本文約250字）

- 推奨投稿日時：9/28(月) 22:00
- トピックタグ：復縁
- 体験の役割：「私も同じだった」で一気に距離を縮める

```
夜になると、元彼とのトークを見返してしまうあなたへ。

【私も昔、別れたあとの数か月、寝る前に必ずトーク画面を開いていました。昼は平気なのに、夜だけ急にさみしくなるんですよね。】

あとから恋愛心理学を学んで知ったのは、夜は疲れて心のブレーキが弱まり、さみしさが大きく感じやすい時間だということ。
つまり「まだ好きだから」だけじゃなく、「夜だから」も混ざっているんです。

だから夜に出した答えは、朝もう一度確かめてみて。
朝になっても同じ気持ちなら、それはあなたの本音です🌙

あなたは、夜に思い出す派？朝も思い出す派？
```

## 投稿2：返信が来ない1日（本文約270字）

- 推奨投稿日時：10/1(木) 21:30
- トピックタグ：片思い
- 体験の役割：「なぜ恋愛心理学を学んだのか」という**さきさん自身の原点**を伝え、アカウントへの信頼につなげる

```
返信が来ない1日って、なんであんなに長いんだろう。

【片思いしていた頃の私は、既読がついたまま返事が来ないと、占いアプリを何度も開いては「脈なし」の文字におびえていました。】

でも調べてみたら、約半数の人が「返信が1日来ないと遅い」と感じるそう。
つまりその不安、あなただけじゃないんです。

そして彼にとっての1日は、ただ「忙しかった1日」なことも多いもの。
【私が恋愛心理学を学び始めたのも、この“待つ時間”を少しでもラクにしたかったから。】

今日は通知を切って、自分のための時間をひとつ作ってみて✨

返信を待つ時間、あなたはどうやって過ごしてる？
```

> 📊 「約半数」の根拠：ハッピーメール「カップルのLINE実態調査」（2026年3月）で、既読後に遅いと感じる境目は「1日」が48.00%で最多。調査は男女が対象なので「女性の」ではなく「約半数の人が」と表記しています。

## 投稿3：金星逆行と、送りかけた「元気？」（本文約250字）

- 推奨投稿日時：10/4(日) 21:00（金星逆行2日目）
- トピックタグ：金星逆行
- 体験の役割：「送る前に本音を見つける」という行動のヒントを、自分の実例で見せる

```
10/3から金星逆行が始まりました。
過去の恋をふと思い出しやすい時期と言われています。

【実は私も以前、別れた彼に「元気？」と送りかけたことがあります。
でも送信ボタンの上で指が止まって、気づいたんです。
私が本当に伝えたかったのは「元気？」じゃなくて「あの時わかってほしかった」だったって。】

思い出すこと自体は、悪いことじゃない。
金星逆行は“送るための時期”というより、自分の本音を見つける時期。
その言葉が見つかったら、送るかどうかはそれから決めても遅くありません。

あなたが本当に伝えたい一言は、何ですか？🌙
```
