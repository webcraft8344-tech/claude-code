## 投稿1：夜になると元彼を思い出す（本文255字）

- 推奨投稿日時：9/28(月) 22:00
- トピックタグ：復縁
- 体験の役割：「別れの原因は私の束縛」という正直な告白で、距離を縮める

```
夜になると、元彼とのトークを開いては閉じてしまうあなたへ。

私が彼と別れた理由は、私の束縛でした。
だから連絡したくても「また重いと思われたら」と怖くて、ずっと動けずにいました。

あとから恋愛心理学を学んで知ったのは、夜は疲れて心のブレーキが弱まり、不安やさみしさが大きく感じやすい時間だということ。
「まだ好きだから」だけじゃなく、「夜だから」も混ざっているんです。

だから夜に出した答えは、朝もう一度確かめてみて。
朝になっても同じ気持ちなら、それはあなたの本音です🌙

あなたは、夜に思い出す派？朝も思い出す派？

— さき
```

## 投稿2：返信を待つ時間（本文248字）

- 推奨投稿日時：10/1(木) 21:30
- トピックタグ：恋愛心理学
- 体験の役割：さきさんが実際にした「3つのこと」を見せる。のちの「3つの逆転戦術」への伏線

```
返信が来ない時間って、なんであんなに長いんだろう。

付き合っていた頃の私は、その時間に耐えられず、彼を束縛してしまいました。
それが、別れの原因です。

別れてから私がしたのは、3つだけ。
友人との時間を増やすこと。
彼に依存しない生き方を見つけること。
感情的にならない伝え方を学ぶこと。

そうして気づいたのは、返信を待つ時間がつらいのは、彼のせいじゃなく「私の毎日が彼だけでいっぱいだったから」でした。

今日は通知を切って、友達との予定をひとつ入れてみて🌙

返信を待つ時間、あなたはどうやって過ごしてる？

— さき
```

## 投稿3：金星逆行と、“もう一度だけ”の一通（本文252字）

- 推奨投稿日時：10/4(日) 21:00（金星逆行2日目）
- トピックタグ：金星逆行
- 体験の役割：復縁できたきっかけ（もう一度だけ動いた）を、少しだけ明かす。全部は LINE 4日目で

```
10/3から金星逆行が始まりました。
過去の恋を見つめ直すのに向いた時期と言われています。

私が復縁できたのは、執着を手放してから“もう一度だけ”動いたからでした。
送ったのは、責める言葉でも、すがる言葉でもない、短くて軽い一通。
束縛していた頃の私には、書けなかった言葉です。

思い出すこと自体は、悪いことじゃない。
金星逆行は“送るための時期”というより、送る言葉を整える時期。
心が軽くなってから選んだ言葉は、ちゃんと相手に届きやすくなります。

今のあなたが送るなら、それは「すがる一通」？「軽い一通」？🌙

— さき
```
