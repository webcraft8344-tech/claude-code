## 3. 投稿案（6本・1本投稿）

型：参考の「〜すぎて」「自分でも気づいていない本音」＋これまで伸びた「未来の日付＋その前に＋見分け方」

### 案1：好きすぎて、握りしめた（生い立ち）　タグ：復縁
```
好きすぎて、握りしめて、失いました。

返事が遅いと問い詰めて、
離れていく気配があれば、もっと強く握った。
握るほど、あの人は遠くなっていきました。

手放して、心を整えて、もう一度だけ連絡した時。
止まっていた縁が、また動き出しました。

だから私は、あなたの「握り方のくせ」が分かります。
責めるためではなく、手放す場所を見つけるために。

当てはまった方は「私も」とだけ。
```

### 案2：自分でも気づいていない本音は、口ぐせに出る　タグ：恋愛心理学
```
はっきりお伝えします。
自分でも気づいていない本音は、口ぐせに出ます。

「大丈夫」が口ぐせの人は、本当は、誰かに頼りたい。
「別にいい」が口ぐせの人は、本当は、選んでほしい。
「どうせ」が口ぐせの人は、本当は、期待したい。

口ぐせは、心が守ってきた場所の目印です。

今日、自分がいちばん言っている言葉を一つ、思い出してみてください。

当てはまった方は「私も」とだけ。
```

### 案3：慰めの嘘は言わない　タグ：占い
```
私は、慰めの嘘を言いません。

心理学、星の配置、あなたの言葉。
三つが一点で交わった時だけ、答えを出します。
交わらない時は、「まだです」と伝えます。

「大丈夫、うまくいくよ」と言うのは簡単です。
でも、根拠のない「大丈夫」は、あとであなたを、もっと苦しめる。

だから、本当のことだけを、やさしく伝えたいのです。

必要な方だけ、固定投稿からどうぞ。
```

### 案4：好きになるほど冷たくする人の本音　タグ：恋愛相談
```
好きになるほど、冷たくしてしまう方。
自分でも気づいていない本音が、そこにあります。

冷たくするのは、嫌いだからではありません。
「近づいて、また傷つくのが怖い」から。
先に距離をとれば、置いていかれずに済む。
心は、そうやってあなたを守ってきたのです。

今日ひとつだけ。
冷たくしたくなったら、「ごめん、今ちょっと照れてる」と一言足してください。

当てはまった方は「私も」とだけ。
```

### 案5：「大丈夫」と言い続けてきた人へ（新ペルソナ）　タグ：自己肯定感
```
はっきりお伝えします。
誰にも頼らずに生きてきた人ほど、
「大丈夫」が口ぐせになっています。

本当は、大丈夫じゃない日もあった。
でも、「大丈夫じゃない」と言える場所がなかった。
だから、大丈夫でいるしかなかったのです。

その強さは、あなたを守ってきた鎧です。
ただ、鎧の中の本音にも、居場所をつくってあげてほしい。

今日、誰にも見せない紙に一行だけ。
「本当は、大丈夫じゃなかった」。

当てはまった方は「私も」とだけ。
```

### 案6：未来の日付＋その前に＋見分け方（閲覧1,000超えの型）　タグ：新月
```
12月9日、射手座の新月まで、あと2週間あまり。
新しい始まりに向かいやすいと言われる時期。
その前に、「手放していい恋」と「待っていい恋」の見分け方を知っておいてほしくて・・・

手放していいのは、思い出すたびに、自分を責めてしまう恋。
待っていいのは、思い出すと、自分が少しやさしくなれる恋。

どちらかを決めるのは、相手ではなく、あなたの心です。

当てはまった方は「私も」とだけ。
```
