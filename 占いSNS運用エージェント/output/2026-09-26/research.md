## 3. Threads で伸びている投稿の傾向

### アルゴリズム・運用面（2026年）
- **いいね数より「返信数」が最重要**。投稿の最後に、つい答えたくなる質問を入れる
- 投稿頻度は1日1〜3本が目安。最低でも週3本
- 返信にさらに返信して、会話を続けるとリーチが伸びる
- 画像だけでなく、必ずテキストで説明を添える（アルゴリズムが内容を理解するため）

### 占い・恋愛アカウントで多い型
| 型 | 例（構造のみ・文章は引用しない） | 伸びる理由の仮説 |
|----|--------------------------------|------------------|
| **「あるある」共感で始める** | 「夜になると急に思い出さない？」→ 気持ちの説明 → 今やるべきこと | 1行目で「私のことだ」と思わせる |
| **常識をひっくり返す** | 「〇〇すると戻れる、って言われるけど実は逆効果なことも」 | 意外性で最後まで読まれる |
| **問いかけで本心に気づかせる** | 「本当に戻りたいのは、その人？それとも…？」 | 返信で自分の気持ちを語りたくなる |
| **彼の心理を解説する** | 「忙しい彼に一番刺さるのは〇〇な女性」 | 相手の気持ちを知りたい欲求に直接応える |
| **コメント参加型の占い** | 「止まった数字をコメントしてね」→ 結果を返す | 返信数が一気に増え、アルゴリズムに乗りやすい |

## 4. 競合分析

### ニッシー｜恋愛占い師×引き寄せ占導師（@nissy_lovelife）
- **展開**：Instagram（鑑定実績3,000件以上とプロフィールに記載）、Threads、YouTube、ココナラ、note
- **扱う悩み**：出会い、片思い、相性、彼の気持ち、複雑な恋愛、結婚、離婚、復縁など幅広い
- **手法**：心理学・恋愛学と「潜在意識の書き換え（引き寄せ）」を組み合わせている
- **Threads の投稿形式**：動画で「止まった数字をコメントに書くと、DMで結果を届ける（フォロワー限定）」という**コメント → フォロー → DM** の流れ
- **集客の導線**：ワンコイン鑑定（note）→ ココナラでの有料鑑定
- **参考にする点**
  - 「心理学 × 占い」という組み合わせは自アカウントと近い。**差別化のポイントは「星回り」と「AI」**。例：「心理と星の両方から見ると…」という二重の根拠を毎回見せる
  - コメント参加型の形式は Threads の返信数を増やすのに有効。**ただし「DMを送るからフォローして」は依存・誘導に見えないよう注意**。自アカウントではコメントへの**公開返信**で結果を返す形がおすすめ
  - 低価格の入口商品 → 有料鑑定という流れは、有料鑑定 月20件の目標にも使える

  - 同じ占いを YouTube（長尺）・リール / TikTok（短尺）に展開する**マルチプラットフォーム型**
- **参考にする点**

  - 差別化：マユコさんは「タロット＋霊視」、さきさんは「恋愛心理学＋星回り＋AI」。**根拠を言葉で説明できる**点を前面に出す
- **限界**：Threads・Instagram のページは本文を開けず（ログインが必要なため）、個別投稿の反応数は確認できていません

### 参考：復縁・片思いジャンルで Threads に多いアカウント名の傾向
