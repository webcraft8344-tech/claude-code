## キャプション

### reel0-intro.mp4（最初の投稿）
```
私は、愛する人を縛り、失った。

何も見えない夜、ひとつの占いが私を救った。
「今は動く時ではない。まず、あなた自身を整える時」

執着を手放し、“もう一度だけ”動いた刻、
止まっていた縁は、再び巡り出した。

答えは、心と、星と、言葉の中にある。
三つが交わる一点しか、私は語らない。

復縁の星図師、紗希。
止まった恋と人生の配置を、ここで読み解いていく。

あなたの縁は、まだ星図の上に残っている。
フォローして、刻を待て。
無料鑑定は、プロフィールのLINEから。

#復縁 #復縁したい #恋愛占い #星読み #恋愛心理学 #占い #占い師 #元彼 #片思い #星図師紗希 #復縁の星図
```

**冒頭3秒の設計**
- 0秒目から文字が出ている（フェードインなし）：「私は、愛する人を縛り、失った。」＝占い師が自分の失敗を告白するという意外性
- 同時に人物画が大きく寄った状態から、0.9秒かけて引いていく動き
- 「失った。」だけ金色にして、目線を最後の一語に集める
- カバー画像も同じ場面（`reel0-intro-cover.jpg`）

### reel2-shocho.mp4
```
三つの象徴のうち、どれに目が留まるかで、今週のあなたの配置が見えてくる。

一　月
二　羅針盤
三　古い地図

選んだ数を、コメントに置いていきなさい。
保存して、迷った日に読み返すこと。

占いは、あなたが自ら選ぶための地図である。

#恋愛占い #星読み #選択式占い #復縁 #片思い #恋愛心理学 #直感占い #占い #星図師紗希 #復縁の星図
```

### reel3-tsuki.mp4
```
復縁を望む人ほど、ある日ぷつりと、何もできなくなる。

それは、弱いからではない。
心は、月に似ている。
待つたびに、言葉を飲み込むたびに、少しずつ欠けていく。

動けなくなったのは、それだけ想い続けてきた証だ。
欠けた月は、新月を越えて、また満ちていく。

今のあなたの心は、何日目の月か。コメントに一言だけ。

#復縁 #復縁したい #恋愛心理学 #恋愛占い #星読み #新月 #元彼 #連絡できない #占い #星図師紗希 #復縁の星図
```
