## 1. 構造の分解

### 投稿A「人生で一番好きだったのは、旦那さんではない」
| 本 | 中身 | 役割 |
|----|------|------|
| 1本目 | 「よく聞いて下さい」＋**人に言えない本音の代弁**（夫は好き。でも一番ではない）＋「そんな方、いますか」 | ①呼びかけで止める ②**タブーの本音**を代わりに言う ③**名乗り出たくなる問い** |
| 2本目 | 「未練だけではない」→ 根拠（霊視・何百人）→ **新しい概念**（一番好きになる縁／一緒に生きる縁は役目が違う）→ **どちらも間違いではない** → 「苦しいなら〜のサインかも」 | ④常識の反転 ⑤権威 ⑥**二つの縁という新しい言葉** ⑦**両方を肯定して罪悪感を外す** |
| 3本目 | 「責めなくていい」「裏切っているわけでもない」→「固定投稿からご相談を」 | ⑧免罪 ⑨柔らかい導線 |

### 投稿B「不倫をする男性の特徴 第1位は」
| 本 | 中身 | 役割 |
|----|------|------|
| 1本目 | 「はっきりと伝えます」＋**ランキングの第1位**＋意外な答え（外面がいい） | ①宣言 ②**ランキング**（続きが気になる） ③意外性 |
| 2本目 | 「イケメンという意味ではない」と定義し直す → 具体的な行動の描写 → 権威（霊視・波動）→ **外と内の差**という対比 → **見るのは一つだけ**（二人きりの時の扱い）→ **名言で締める**（本当の顔は誰も見ていない場所に出る） | ④言葉の定義し直し ⑤具体描写 ⑥**対比** ⑦**一つだけ見ればいい** ⑧**名言の締め** |
| 3本目 | **違和感の言語化**（気のせいだと言い聞かせていませんか）→「直感は正しい」→「固定投稿から視ますよ」 | ⑨モヤモヤの代弁 ⑩肯定 ⑪導線 |

### 反応が多い理由（共通する型）
1. **人に言えない本音を、先に言ってあげる**（夫が一番ではない／彼の優しさを疑っている）→「私のことだ」とコメントしたくなる
2. **ランキング・第1位**で、続きを開かせる
3. **二つの言葉の対比**で、モヤモヤに名前をつける（一番好き／一緒に生きる、外の顔／内の顔）
4. **どちらも間違いではない**と、罪悪感を外す
5. **見るのは一つだけ**と、行動を一つに絞る
6. **名言で締める**（保存・引用されやすい）
7. 3本目は**免罪＋柔らかい導線**（固定投稿から）

### 紫苑は使わないもの
| 使わない | 理由 | 代わりに |
|----------|------|----------|
| 霊視・波動・「何百人と視てきた」 | 持っていない力と、まだない実績（`CHARACTER.md` 8章） | **星図**（金星＝恋、月＝暮らし）、**恋愛心理学**、**束縛して復縁した当事者** |
| 「あなたの直感は正しいです」 | 確かめずに断定すると、相手を疑い続ける方向へ背中を押しかねない | 「違和感を、なかったことにしなくていい」 |
| 不倫の見分け方そのもの | 紫苑の読者（復縁）から外れる。特定の人を疑わせる内容になりやすい | 構造（ランキング・外と内・一つだけ見る）だけを、復縁の悩みに使う |

## 2. 投稿案（3連投×6本）

- 1行目は、これまでのデータどおり「宣言・反転・ランキング・タブーの問い」で始める（「私も」は1行目に置かない）
- 2本目は、元ネタに合わせて長め（80字を超える）。**「2本目を長くしても最後まで読まれるか」の試験**も兼ねる
- 3本目の最後は「当てはまった方は『私も』とだけ」。導線は「固定投稿からどうぞ。必要な方だけで大丈夫です」

### 案1：金星の縁と、月の縁（元ネタA の転用）　タグ：星読み
**1/3**
```
よく聞いてください。
今の人のことは、ちゃんと好き。
でも、人生でいちばん好きだったのは、今の人ではない。
そんな方、いますか。
```
**2/3**
```
忘れられないのは、未練だけではありません。
あの人の前でだけ、飾らずにいられた自分がいたから。弱音も、わがままも、素のまま出せた。
その頃の自分にもう一度会いたくて、ふとあの人の顔が浮かぶのです。

星図では、恋の星・金星と、暮らしの星・月は、役目が違います。
いちばん好きになる人は、金星の縁。本当の愛し方を教えに来る人。
一緒に生きる人は、月の縁。その愛し方を、毎日の暮らしで続けていく人。
だから、今の人を選んだことも、あの人を忘れられないことも、どちらも間違いではありません。
```
**3/3**
```
あの人を思い出す自分を、責めなくていい。
今の人を裏切っているわけでもありません。
ただ、あの頃の自分が、まだ心の中で待っているだけ。

当てはまった方は「私も」とだけ。
その縁の意味を知りたい方は、固定投稿からどうぞ。必要な方だけで大丈夫です🌙
```

### 案2：私が復縁する前にやめたこと 第1位（元ネタB のランキング型）　タグ：恋愛心理学
**1/3**
```
はっきりお伝えします。
復縁する前に、私がやめたこと。
第1位は、「確かめること」でした。
```
**2/3**
```
既読がついたか。返事は何分で来たか。SNSで誰といるか。
束縛していた頃の私は、一日に何度も彼を確かめていました。
確かめるほど不安は増えて、増えた不安が、また確かめさせる。
その輪から降りた日から、心は少しずつ静かになりました。

第2位は「感情のまま送ること」。
第3位は「一日を、彼の予定で埋めること」です。
```
**3/3**
```
もし今、一日に何度も彼を確かめているなら、ひとつだけ。
今日は、一回だけ減らしてみてください。
減らせた一回が、あなたの時間を取り戻す、最初の一回です。

当てはまった方は「私も」とだけ。
```

### 案3：彼の本音が出る場所（元ネタB の「外と内」「一つだけ見る」）　タグ：恋愛心理学

**2/3**
```

前に話した予定、好きなもの、落ち込んでいたこと。

```

### 案4：誰にも言えない「復縁したい」（元ネタA の「言えない本音」）　タグ：恋愛相談
**1/3**
```
よく聞いてください。

当てはまった方は「私も」とだけ。
誰かに話したくなった方は、固定投稿からどうぞ。必要な方だけで大丈夫です🌙
```

## 3. 使い方
- **案5は 10/23〜10/26 のどこかで使うのがいちばん効く**（蠍座シーズンの旬）。10/22 昼（蠍座）と入れ替えてもよい
- 案1・案4 は、既婚者や「誰にも言えない」層に広がる。紫苑の読者（復縁）の外側に届く
- 案2 は紫苑の体験談の中心。深い読者（セッションに近い人）向け
- 各案の翌日に「1本目の表示・2本目／3本目の表示・返信・プロフ閲覧・フォロー」を記録し、どの型（タブーの問い／ランキング／一つだけ見る）が強いかを比べる
