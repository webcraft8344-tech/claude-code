## 1. アカウントコンセプト

### ひと言で
**「3つの視点が一致した答えだけを届ける、恋の案内人」**

### コンセプト文
> 恋の答えを、ひとつの占いだけで決めない。
> 人の心の動き（恋愛心理学）、時の流れ（星回り）、言葉のくせ（AI解析）。
> 3つの視点が同じ方向を指したときだけ、それを「答え」として伝える。
> 揃わないときは、揃わないと正直に言う。
> それが、さき＠愛され案内人のやり方です。

### 競合との立ち位置

| | マユコさん | ニッシーさん | **さき** |
|---|---|---|---|
| 根拠 | タロット＋霊視（見える力） | 引き寄せ・潜在意識 | **心理学＋星回り＋AI解析（説明できる根拠）** |
| 語り口 | くだけた関西弁・エンタメ性 | 前向きな引き寄せの言葉 | **静かで短い言葉。多くを語らない** |
| 答え方 | メッセージを届ける | 願いは叶うと背中を押す | **3つが揃った時だけ答える／揃わない時は「まだ」と言う** |
| 入口 | リール・前世診断など間口広め | コメント→DM | **LINEで「恋の星図」ミニ鑑定** |

**差別化の核は「答えないこともある占い師」**。
他の占い師がどんな相談にも答えを出す中で、「3つが揃わないので、今は答えを出しません。代わりに揃うまでにできることを伝えます」と言える。この**抑制**が「この人の言うことは他と違う」「この人が言い切る時は本当なんだ」という信頼と権威になります。

## 2. 世界観

### 2-1. 世界観の設定：「恋の星図（こいのせいず）」

さきは、**一人ひとりの恋を「星図（ほしのちず）」として読み解く案内人**。

- 星図は3枚の層でできている
  1. **心の層**（恋愛心理学）：あなたと彼が、今どんな心理状態にいるか
  2. **時の層**（星回り）：今は動く時か、待つ時か
  3. **言葉の層**（AI解析）：あなたの相談文・彼のLINEの言葉に表れるくせやパターン
- 3枚を重ねて、**同じ場所に光が重なった部分だけ**を「答え」と呼ぶ
- 案内人は、行き先を決めない。**地図を広げて、どの道が照らされているかを見せる**だけ

### 2-2. 「正体の謎」と「権威」を両立させる仕掛け

実在しない経歴や資格は作りません。**事実だけで、謎と権威を感じさせる**仕掛けです。

| 仕掛け | 内容 | ねらい |
|--------|------|--------|
| **① 顔を出さない** | アイコンは「月と羅針盤」のモチーフ。写真は手元・後ろ姿・星図の画像のみ | 正体の謎。見る人が自由に想像できる |
| **② 経歴は「一文だけ」** | 過去は多く語らない。プロフィールと固定投稿で、体験を一文だけ出す（「復縁に悩み動けなかった私が、執着を手放し“もう一度だけ”で復縁」）。詳しい話は LINE の4日目配信でだけ語る | 語らないことで「何があったんだろう」と気になる。続きを知る場所＝LINE |
| **③ 独自の用語** | 「恋の星図」「3つの層」「光が重なる」「まだ揃っていない」など、さき専用の言葉を繰り返し使う | 他のアカウントにない言葉＝他と違う存在だと感じる |
| **④ 答えない勇気** | 「今回は3つが揃わなかったので、答えは出しません」と公開で言う投稿を、月1〜2回入れる | 抑制が権威になる。「言い切る時は本物」と思わせる |
| **⑤ 鑑定記録番号** | ミニ鑑定に「星図 No.001」から通し番号をつける。事例紹介（本人の同意を得たもの）にも番号を添える | 件数ゼロからでも、番号が静かに積み上がっていく様子が伝わる（番号は実数のみ・水増ししない） |
| **⑥ 署名** | 投稿の最後に「— さき」または「🌙」だけを置く | 一人の案内人が、一人ずつ書いている感覚 |
| **⑦ 多くを語らない文体** | 1文を短く。説明しすぎない。質問には「問い」で返すこともある | 静かな余白が「わかっている人」の雰囲気になる |

### 2-3. 言葉づかいのルール

| 使う | 使わない |
|------|----------|
| 「星図が示しているのは〜」「3つの層が重なったのは〜」 | 「視えました」「波動が〜」（霊視・スピ系は競合の領域） |
| 「まだ揃っていません」「今は待つ時と出ています」 | 「絶対」「必ず」「運命確定」（`CLAUDE.md` 3章） |
| 「あなたが決めていい」「地図を広げるだけ」 | 「私の言う通りにすれば」 |
| 短い文、余白、問いかけ | 長い説明、絵文字の多用（1投稿1〜2個まで） |

### 2-4. ビジュアル

- **色**：深い藍（夜空）＋ 生成り（紙の地図）＋ 金（光が重なる点）
- **モチーフ**：月、羅針盤、星座を結ぶ線、古い地図
- **フォント**：明朝体（静かさ・知性）。ポップ体は使わない
- **アイコン**：月と羅針盤を重ねた線画（顔は出さない）

### 2-5. AIの扱い（透明性）

「AI解析」は隠さず、**道具として正直に**伝えます。
- 伝え方：「相談文の言葉のくせを、AIで整理してから読み解いています。最後に読むのは私です」
- 相談者の名前・連絡先などはAIに入力しない（生年月日と相談内容のみ、匿名で扱う）

## 5. 無料ミニ鑑定の中身

### 5-1. 「3つの逆転戦術」とは

3つの層から、それぞれ1つずつ戦術を出します。**戦術は層と1対1で対応**するので、本鑑定の梅・竹・松とそのままつながります。

| 戦術 | 出どころ | 内容の例 |
|------|----------|----------|
| **戦術① 心の逆転** | 心の層（恋愛心理学） | 執着を手放し、彼から見た「あなたの印象」を変える戦術 |
| **戦術② 時の逆転** | 時の層（星回り） | 動くのを止める時期と、“もう一度だけ”動く時期を見極める戦術 |
| **戦術③ 言葉の逆転** | 言葉の層（AI解析） | 次に送る一通の「言葉選び」を変える戦術 |

さきさん自身の体験（執着を手放す → 時期を待つ → もう一度だけ動く）が、そのまま3つの戦術の型になっています。

### 5-2. ミニ鑑定の構成（600〜800字）

```
【恋の星図 No.［通し番号］】［ニックネーム］さんへ

■ 今のふたりの星図
（3つの層を重ねて見えた、今の関係の状態を3〜4行で）

■ あなたの「3つの逆転戦術」
① 心の逆転：［戦術名］
　 なぜこの戦術か（1〜2行）／今日からできる最初の一歩（1行）
② 時の逆転：［戦術名］
　 なぜこの戦術か（1〜2行）／今日からできる最初の一歩（1行）
③ 言葉の逆転：［戦術名］
　 なぜこの戦術か（1〜2行）／今日からできる最初の一歩（1行）

■ 3つが重なった場所
（3つの戦術が同じ方向を指している部分を1つだけ）
※ 揃わなかった場合は「今回はまだ揃っていません。揃うまでは①の一歩から」と書く

■ 最後に
それぞれの戦術を「いつ・どう進めるか」の詳しい道順は、
本鑑定でお伝えしています。必要な方だけ、メニューからどうぞ。
まずは、今日の一歩からで大丈夫です。

— さき
```

**無料でも価値が残るように**：3つすべてに「なぜ」と「最初の一歩」を書く。有料で渡すのは「その先の詳しい道順」です。「続きは有料」で途中を切らない。

**各戦術の「詳しい道順」に入れる内容**（1戦術あたり約1,300〜2,000字）
- 戦術の全体像と、なぜあなたに合うのか

- 心の逆転：執着を手放すためのワーク、彼から見た印象の変え方
- 時の逆転：今後3か月で「動く日」の候補と、動かない方がいい時期
- 言葉の逆転：送る一通の文面例（2〜3パターン）と、避けたい言葉
- やってはいけないこと（NG行動）
- 松のみ：3つの戦術を、どの順番で・いつ進めるかの**統合スケジュール**

```
それが、今あなたにお届けしている「3つの逆転戦術」の原点です。

同じ結果を約束することはできません。
でも、あなたが自分で決めて、軽い心で動けるように。
そのための地図なら、一緒に広げられます。

— さき
```
